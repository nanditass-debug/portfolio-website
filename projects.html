PROJECTS

Expense Tracker (HTML5,CSS3,JavaScript)

Designed and developed a personal Expense Tracker website to help users manage monthly budgets and monitor spending habits effectively. Implemented category-wise expense tracking with details such as amount, date, and expense type. Created interactive graphs and progress indicators to visualize spending patterns and budget utilization. Added alert notifications and pop-up warnings when expenses approached or exceeded predefined limits. Developed a user-friendly interface with login functionality, improving both usability and data organization. This project strengthened my understanding of JavaScript, data visualization, and user-centric application development.

Shop Management System (HTML5,CSS3,JavaScript,Firebase)

Developed a web-based Shop Management System to simplify billing, inventory management, and customer record maintenance. Implemented features such as product management, bill generation, stock tracking, and customer data handling. Integrated Firebase Authentication for secure user login and Firebase Database for real-time data storage and synchronization. Additionally, incorporated an AI-powered chatbot using Google AI APIs to automate user queries and improve customer interaction. This project enhanced my skills in frontend development, database integration, and real-world application design.
